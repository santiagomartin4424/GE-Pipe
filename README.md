# Automatic-Generation-of-ML-pipelines-using-PonyGE2, a Grammatical Evolution Method 🌿

GE-Pipe is an implementation based on the [PonyGE2](https://github.com/PonyGE/PonyGE2) library (that uses Grammatical Evolution, GE), in order to solve the Automatic Workflow Composition (AWC) problem.

In this context, GE is a type of Evolutionary Algorithm that evolves a population of ML pipelines, in order to explore the solution space and find the best performing pipeline for a given dataset.

To test it, and run a default example (regression), just clone this folder, unpack the datasets, and execute:
```bash
tar -xzf datasets.tar.gz
python ponyge.py
```


# Generación Automática de Pipelines de ML utilizando PonyGE2, una método de Evolución Gramatical 🌿

Ge-Pipe es una implementación basada en la librería [PonyGE2](https://github.com/PonyGE/PonyGE2) (que utiliza Evolución Gramatical), como propuesta al AWC problem.

En este contexto GE es un tipo de algoritmo evolutivo que evoluciona una población de ML pipelines, para explorar el espacio de búsqueda y encontrar el mejor pipeline para un dataset dado.

Para probarlo, y ejecutar el ejemplo por defecto (regression) solo tienes que clonar esta carpeta, descomprimir el archivo de datasets, y ejecutar lo siguiente:
```bash
tar -xzf datasets.tar.gz
python ponyge.py
```
