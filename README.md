# Automatic-Generation-of-ML-pipelines-using-PonyGE2, a Grammatical Evolution Method 🌿

In the present work we propose an implementation based on the [PonyGE2](https://github.com/PonyGE/PonyGE2) library (that uses Grammatical Evolution, GE), as a proposal to solve the Automatic Workflow Composition (AWC) problem. It is called GE-Pipe, and it is based on the [PonyGE2](https://github.com/PonyGE/PonyGE2) easy framework. In this context, GE is a type of Evolutionary Algorithm that evolves a population of ML pipelines, in order to explore the solution space and find the best performing pipeline for a given dataset.

To test it, and run a default example (regression), just clone this folder, unpack the datasets, and execute:
```bash
tar -xzf datasets.tar.gz
python ponyge.py



# Generación Automática de Pipelines de ML utilizando PonyGE2, una método de Evolución Gramatical 🌿

En este trabajo ofrecemos una implementación basada en la librería [PonyGE2](https://github.com/PonyGE/PonyGE2) (que utiliza Evolución Gramatical), como propuesta de cara al AWC problem. Se llama GE-Pipe, y está basada en el framework sencillo de PonyGE2. En este contexto GE es un tipo de algoritmo evolutivo que evoluciona una población de ML pipelines, para explorar el espacio de búsqueda y encontrar el mejor pipeline para un dataset dado.

Para probarlo, solo tienes que clonar esta carpeta y ejecutar python ponyge.py para ejecutar un ejemplo sencillo de regresión procedente de la librería de PonyGE2.
Los datasets están comprimidos en un archivo .tar.gz dentro de la carpeta principal.
