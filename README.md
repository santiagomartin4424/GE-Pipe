# GE-Pipe-Automatic-Generation-of-ML-pipelines-using-PonyGE2, a Grammatical Evolution Method

In the present work we propose an implementation based on the PonyGE2 library (that uses Grammatical Evolution), as a proposal to solve the AWC problem. It is called GE-Pipe, and it is based on the PonyGE2 easy framework.

To test it, just clone this folder, and execute python ponyge.py to run a simple regression example of the Ponyge library.
